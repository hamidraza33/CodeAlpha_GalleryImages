🖼️ Interactive Image Gallery — CodeAlpha Task 1

An elegant, modern, and fully responsive Image Gallery application built using HTML5, CSS3, and Vanilla JavaScript. This project was developed as part of the CodeAlpha Frontend Development Internship.

📸 Key Features

Responsive Grid Layout: Built using CSS Grid and Flexbox to deliver a seamless view across Desktop, Tablet, and Mobile devices.

Category Filtering Engine: Real-time dynamic image filtering (e.g., Nature, Cities, Animals) using data attributes without reloading the page.

Lightbox Viewer: Click on any image to open an interactive full-screen modal view with dark overlay styling.

Bounded Loop Navigation: Smooth Next and Previous lightbox controls restricted dynamically to the currently visible/filtered category.

Hover Animations: Glassmorphism UI touch, clean typography, hover scale transitions, and text overlays.

🛠️ Built With

HTML5: Semantic structure and dataset attributes (data-category, data-filter).

CSS3: Flexbox, CSS Grid, media queries, keyframe transitions, and custom styling.

JavaScript (ES6+): Dynamic DOM manipulation, array filtering (Array.from, .filter), event delegation, and state indexing.
